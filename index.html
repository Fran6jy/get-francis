01

Ship the boring reliability first

Fragmented MP4 so an interrupted recording still plays. Append-only audit trails so a correction never destroys history. Offline fallbacks so a missing API key degrades the product instead of breaking it. Demos are cheap, recovery paths are not.

02

A model without a metric is a vibe

My chess imitation network reports move-match accuracy on held out games, the way the Maia papers measure it. An earlier language-model version looked impressive and played illegal moves, so it was deleted. Measurable beats interesting.

03

Deterministic where you can, LLM where you must

In LodgeOS, categorisation is a rule engine with no model in the loop, and the LLM only handles genuine ambiguity behind a provider fallback chain. Cheaper, faster, and it gives you something you can actually regression test.

04

Go down a layer when the layer is the problem

Zero-copy DXGI to NVENC because a memory round trip is the frame budget. Hand rolled Noise plus ChaCha20 datagrams because a generic tunnel adds latency you cannot afford. Abstractions are a default, not a rule.
