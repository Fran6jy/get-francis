# Get Francis

Personal portfolio for **Francis Babatunde**, data engineer and systems builder.

Hand written static site. No framework, no build step, no dependencies.

```
index.html    structure and copy
styles.css    design system
app.js        project data + filtering, reveals, nav
```

## Run locally

```bash
python -m http.server 4321
```

Then open http://localhost:4321

## Editing

Every project lives in the `PROJECTS` array at the top of `app.js`. Add an object,
it renders. Categories map to the filter chips in `index.html`: `data`, `ai`,
`systems`, `product`.
